# REFFIX Monokai Pro для LuCI

Тёмная тема REFFIX Monokai Pro для LuCI в OpenWrt. Оформление основано на Footstrap и согласовано с панелью REFFIX Log Viewer.

## Скорость навигации

Поддерживаемые страницы LuCI открываются без полной перезагрузки: оболочка остаётся загруженной,
а тема отображает только новое представление. В тесте репозитория от 1 августа 2026 года на
OpenWrt 25.12.2 проверили 38 стандартных страниц. Суммарное медианное время оказалось в 2,29 раза
меньше, чем у стандартной темы Bootstrap; на переход приходилось 0–7 запросов вместо 15–47.
Результат зависит от роутера и страницы: большие наборы данных требуют времени на отрисовку.
[Методика и результаты по страницам](docs/benchmark.md); для сравнения изменений повторите тест
на своём роутере.

## Совместимость

Тема собирается только для OpenWrt 25.12 и более новых версий с пакетным менеджером APK. Пакеты IPK/opkg больше не публикуются.

## Установка

Пакет сохраняет идентификатор `luci-theme-footstrap`, чтобы обновление существующей установки не требовало миграции имени пакета. Установите или обновите пакет из настроенного фида, затем откройте **System → System → Language and Style** и выберите **Monokai Pro**.
